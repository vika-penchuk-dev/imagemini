# Запись скриншотов и GIF для ImageMini

Используйте только тестовые файлы из `tests/fixtures/`. Не открывайте личные изображения и файлы из `_local_debug/`. Записывайте работающий ImageMini в Chrome; не собирайте изображения интерфейса из макетов. Инструкция по сочетаниям клавиш [Snipping Tool на сайте Microsoft](https://support.microsoft.com/en-us/windows/apps/use-snipping-tool-to-capture-screenshots); справки ScreenToGif: [запись экрана](https://github.com/NickeManarin/ScreenToGif/wiki/Help-%E2%96%AA-Recording-%F0%9F%93%B9) и [экспорт GIF](https://github.com/NickeManarin/ScreenToGif/wiki/Help-%E2%96%AA-Editor-%E2%9C%8F%EF%B8%8F-%E2%96%AA-Exporting-your-project-%F0%9F%92%BE).

## Подготовка

1. После успешной установки зависимостей откройте PowerShell в каталоге проекта и выполните `npm run dev`.
2. Откройте в Chrome адрес, напечатанный Vite (обычно `http://localhost:5173/`). Убедитесь, что главная страница загрузилась без ошибок.
3. Разверните Chrome на весь экран и установите масштаб страницы 100% (`Ctrl+0`). Для снимков включите полноэкранный режим Chrome клавишей `F11`.
4. Снимайте область страницы через `Win+Shift+S` → «Прямоугольная область». Уведите указатель в пустое место интерфейса. После снимка нажмите уведомление «Ножницы» → «Сохранить как» и укажите путь `docs/media/<имя>.png`.

## Скриншоты

Сделайте отдельный кадр для каждого состояния и сохраните с указанными именами:

1. `01-home.png` — главная страница без загруженного пользовательского изображения.
2. `02-enhancement.png` — загрузите `tests/fixtures/synthetic-png.png`, выберите улучшение, измените один параметр и дождитесь предпросмотра «до/после».
3. `03-background-removal.png` — загрузите `tests/fixtures/contrast-object.svg`, запустите удаление фона, дождитесь завершения и покажите PNG с прозрачностью на шахматном фоне. При первом запуске дождитесь загрузки модели; она занимает около 98,5 МБ.
4. `04-patch.png` — откройте редактор с `contrast-object.svg`, покажите инструмент «Заплатка» и доступные режимы. Не выдавайте синтетический объект за фотографию.
5. `05-layers.png` — в редакторе выделите объект лассо, скопируйте на временный слой, переместите его и примените.
6. `06-batch.png` — добавьте синтетические JPEG, PNG и WebP из `tests/fixtures/`, запустите пакетную обработку и дождитесь статуса завершения.

Проверьте каждый PNG при масштабе 100%: снимок должен показывать только интерфейс и результат, без путей файлов, уведомлений, меню, ошибок и персональных данных. Не изменяйте само содержимое результата обработки. При необходимости обрежьте только внешние края снимка и оптимизируйте PNG без заметной потери качества.

## GIF редактора

### Запись через ScreenToGif

Если ScreenToGif уже установлен, этот способ сразу создает GIF из записи экрана:

1. Откройте `contrast-object.svg` в редакторе ImageMini.
2. Запустите ScreenToGif → **Recorder** и выделите только область редактора Chrome.
3. Установите 12 кадров/с, включите запись указателя, если он нужен для понимания жестов, и начните запись.
4. За 10–15 секунд выполните непрерывно: лассо вокруг объекта → «Копировать» → перетаскивание копии в другое место → «Применить слой» → короткая пауза на результате.
5. Остановите запись, откройте встроенный **Editor**, удалите только лишние начальные/конечные кадры, измените ширину кадра до 900 px с сохранением пропорций и экспортируйте **GIF** в `docs/media/editor-demo.gif`.
6. Проверьте длительность и размер файла. Если GIF больше 8 МБ, уменьшите частоту кадров до 10 или ширину до 800 px и экспортируйте повторно.

### Запись MP4 через Windows и преобразование в GIF

Если ScreenToGif недоступен, используйте встроенную запись области экрана Windows 11 и уже установленный FFmpeg:

1. Нажмите `Win+Shift+R`, выделите область редактора Chrome и нажмите **Начать**.
2. Выполните тот же непрерывный сценарий за 10–15 секунд и нажмите **Остановить**. В Snipping Tool сохраните запись как `docs/media/editor-demo.mp4`.
3. В PowerShell из корня проекта проверьте, что FFmpeg доступен: `ffmpeg -version`.
4. Создайте оптимизированный GIF командой:

```powershell
ffmpeg -i .\docs\media\editor-demo.mp4 -filter_complex "[0:v]fps=12,scale=900:-1:flags=lanczos,split[a][b];[a]palettegen=max_colors=128[p];[b][p]paletteuse=dither=bayer" .\docs\media\editor-demo.gif
```

5. Откройте GIF и проверьте, что выделение, перенос и применение слоя видны отчетливо, без мерцания и ненужных пауз. Если файл больше 8 МБ, повторите с `fps=10` и `scale=800:-1`.

Не ускоряйте и не собирайте GIF из отдельных статичных скриншотов: демонстрация должна быть одной реальной записью работающего приложения. Не добавляйте исходное видео в репозиторий, если оно не нужно для проверки.
