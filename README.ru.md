# ImageMini

**ImageMini — Image Processing & Photo Editing** — браузерное приложение для обработки и редактирования изображений. Обработка выполняется локально в браузере пользователя.

[English](README.md)

## Возможности

- Сжатие JPEG, WebP и оптимизация PNG без потерь
- Конвертация между JPEG, PNG и WebP
- Улучшение изображения с настройками и пресетами
- Изменение размера и увеличение интерполяцией Ланцоша
- Кадрирование, поворот и отражение в редакторе
- Инструмент «Заплатка» в режимах «Однотон» и «Текстура»
- Выделение лассо, временные слои, мягкий и жесткий ластики
- Пакетная обработка, отмена и ZIP-экспорт
- Интерфейс на русском и английском языках
- Светлая, темная и системная темы

Увеличение Ланцошем — интерполяция, не ИИ-суперразрешение. Текстовый инструмент сейчас отключен.

## Запуск в Windows

Требуется Node.js 20 или новее.

```powershell
npm ci
npm run dev
```

Production-сборка и локальный просмотр:

```powershell
npm run build
npm run preview
```

Скриншоты и GIF пока не приложены: браузерная сессия в среде подготовки не смогла открыть локальный сервер. План воспроизводимой записи — [docs/media/RECORDING.md](docs/media/RECORDING.md).
